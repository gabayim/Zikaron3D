APPENDIX A - HOW TO UPLOAD THE 2.15.0 BUILD (two valid paths)
--------------------------------------------------------------------------------
Always run the preflight first; it fails on anything that would break the upload
(version vs live, slug vs EAS project, missing keys, dead legal URLs):

    node scripts/deploy/preflight-ios-release.mjs --live-version 2.14

PATH A - EAS cloud build (no Mac needed)
  The EAS project @zmz.soft/zikaron3d currently has NO builds and NO production
  variables, so set them once (values from Supabase project settings and
  RevenueCat > Project > API keys, Apple public key starts with appl_):

    npx eas-cli@latest env:create --environment production ^
      --name EXPO_PUBLIC_SUPABASE_URL --value "https://<ref>.supabase.co" --visibility plaintext
    npx eas-cli@latest env:create --environment production ^
      --name EXPO_PUBLIC_SUPABASE_ANON_KEY --value "<anon key>" --visibility sensitive
    npx eas-cli@latest env:create --environment production ^
      --name EXPO_PUBLIC_REVENUECAT_APPLE_KEY --value "appl_..." --visibility sensitive

  Credentials, once (interactive; creates or reuses the distribution certificate
  and provisioning profile for com.AdvBig.Zikaron3D):

    npx eas-cli@latest credentials --platform ios

  Then:

    npx eas-cli@latest build  --platform ios --profile production
    npx eas-cli@latest submit --platform ios --profile production

  Without those three variables the uploaded app runs offline and every pack
  reads "unavailable" - the preflight blocks it for that reason.

PATH B - local Xcode archive (how 2.14 was most likely built: zero EAS builds)
  On the Mac that signed 2.14:
    npx expo prebuild --platform ios --clean
    open ios/*.xcworkspace
      - confirm Version 2.15.0 and Build 215 (they come from app.json)
      - keep a .env with the three EXPO_PUBLIC_* values next to app.json, the
        JS bundle step reads it
    Product > Archive > Distribute App > App Store Connect > Upload

EITHER PATH - right after the upload
  [ ] Wait for processing, then check TestFlight: the build shows as 2.15.0 (215).
  [ ] Attach it on the version page (+ Build) and run TESTFLIGHT_TEST_PLAN.md.
  [ ] Then continue from STEP 7 above.
